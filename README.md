### 바뀌는 동작

- 우르마크르 뒤 MP 표시가 `9/3`처럼 나올 수 있습니다. 쓴 만큼 회복되지 않는 일회성 보충입니다.
- 저주 상태로 종족을 바꾸면 저주 장비는 원본처럼 사라집니다.
- 다른 상점에서 판 물건이 오란드 상점 재고로 옮겨가는 동작은 그대로입니다.
- 충전식 네 종은 횟수가 최대치를 넘을 수 있어 원본 판매가 공식을 유지합니다.
- 이미 망가진 세이브 값은 되돌리지 않습니다. 사라진 강철헤어밴드 재고나 고정된 9/9 MP가 그렇습니다.
- 왕에게 보고하지 않고 최종전을 끝내면 반지 보고 대사와 이어지는 장면은 원본처럼 볼 수 없습니다. 이벤트 기록만 채워집니다.

버그 수정은 해당 코드를 원본과 패치본에서 각각 실행해 비교하는 94개 검사로 확인했습니다. 이벤트 기록은 게임의 스크립트 처리 코드로 10가지 상태를 돌려 비교했습니다. 버그를 모두 실제 플레이로 재현해 본 것은 아닙니다.

작은 지도와 증식 정지는 코드에서 확인한 결함을 고친 것입니다. 작은 지도는 왜 L/R 이동에서 자주 보이는지 확정하지 못했고, 증식 정지는 칸이 마른 뒤 어디서 멈추는지 확인하지 못했습니다. 두 증상이 사라졌는지는 플레이로 확인해야 합니다.
